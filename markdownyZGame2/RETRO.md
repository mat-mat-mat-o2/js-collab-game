# Jedna poprawa na następny collab

Można zgłosić uwagę pisemnie lub powiedzieć PASS. Ten dokument nie zawiera ocen osób.

- Co pomogło? Konkretny przykład:
- Co utrudniało? Zdarzenie, nie etykieta osoby:
- Co proponujemy zmienić?
- Jeden wybrany eksperyment:
- Kto dopilnuje wykonania?
- Po czym sprawdzimy efekt?
- Kiedy wrócimy do wyniku?
- Wynik po następnym collabie: zachowujemy / zmieniamy / odrzucamy, bo...
